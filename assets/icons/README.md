# Application icon

`monitor.svg` is original geometric artwork created for OLED Anti-Dimming without external artwork or references. It is licensed under the project's GPL-3.0-only license.

`monitor-preview.png` is its transparent preview. `monitor.ico` contains 16, 24, 32, 48, 64, 128, and 256-pixel versions for Windows. The same embedded icon is used by the executable, application window, and system tray.
