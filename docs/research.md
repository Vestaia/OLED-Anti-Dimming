# Research record

Initial review: 2026-10-07. No hardware experiments performed.

- User requirement: relative webcam calibration, iterative scene-dependent HDR boost, and investigation of the latency difference between dwm_lut and hardware calibration.
- User correction: additive subpixel-power hypothesis applies to QD-OLED; WOLED is the more complex case.
- Selected first step: isolated HDR stimulus and measurement prototype. This separates physical feasibility from system-wide injection risk.
- Static 3D LUT alone rejected as a complete model because identical pixels require different corrections under different surroundings.
- Legacy VCGT rejected as the primary HDR path because Microsoft documents undefined HDR behavior for the legacy gamma pipeline.
- MHC2 retained for static boost and update feasibility; the supported interface is profile-based, with matrix and 1D LUT rather than arbitrary 3D LUT or direct runtime control.
- DWM retained as an experimental backend. Disabling DirectFlip/MPO is a plausible contributor to the reported latency, not a measured diagnosis.
