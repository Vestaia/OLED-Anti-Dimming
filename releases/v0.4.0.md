This update improves calibration, filter performance, and the application controls.

- Uses a smoothed HSV distribution model with adaptive sampling, zero-correction anchors, and additional refinement.
- Reduces filter overhead and keeps existing measurements usable.
- Improves camera feedback, convergence, and reference-drift handling.
- Adds more licensed photo validation images.
- Requires HDR on the selected display before calibration or Apply.
- Adds an Express calibration button and simplifies the layout, including aligned controls and fixed-width Apply/Disable buttons.
- Adds Delete all data to remove calibration data, caches and logs, disable startup, and exit. Locked files are removed at restart.
- Adds a delay between filter activation and brightness correction to allow the presentation transition.

Download `OledCalibration.exe` below. It is a compressed, self-contained Windows x64 executable.

The application remains beta software. The recent game-related system crash is still under investigation; the activation delay has not been verified as a complete fix.
